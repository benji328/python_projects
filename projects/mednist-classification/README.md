# MedNIST Classification Experiment

A MONAI/PyTorch medical-image classification notebook using the MedNIST dataset.

The original archive included a local copy of MedNIST and a compressed dataset archive. Those third-party data files are intentionally excluded from this public repository. Place MedNIST under:

```text
data/MedNIST/
```

before running the notebook.

Notebook outputs and local absolute paths were removed during repository cleanup.
