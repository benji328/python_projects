# Steam Review / Electronic Arts Data Exploration

Exploratory web-scraping and API notebooks for collecting Electronic Arts titles from Steam, retrieving review data, and combining it with stock-market data.

The notebooks are research prototypes rather than a production scraper. Steam endpoints and page structure may have changed since the original work.

## Data

Scraped/retrieved CSV files from the original workspace are not redistributed in this public repository. Use the notebooks to recreate the data where permitted by the current upstream terms.
