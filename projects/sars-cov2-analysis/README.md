# SARS-CoV-2 Data Analysis

Exploratory epidemiology/genomics notebooks from an earlier research project.

The workspace includes:

- binary-matrix experiments;
- SARS-CoV-2 metadata/sequence exploration;
- Mexico COVID-19 statistical analysis;
- Kaplan-Meier and Cox proportional-hazards experiments;
- selected generated plots and compact aggregate result tables.

## Data note

Large raw/processed CSVs, viral sequence files, and source metadata from the original workspace are intentionally not committed. The notebooks now use relative paths instead of local `/Users/...` paths.

To reproduce the full analysis, obtain the relevant source datasets independently and place them under this project's `data/` directory using the filenames referenced in the notebooks. Check the current redistribution/use terms of each upstream source before sharing raw data.
