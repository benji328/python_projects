# Public Repository Cleanup

This repository was created from a large personal Python workspace.

## Removed from the public export

- nested `.git` histories;
- Jupyter checkpoint folders;
- notebook outputs/execution state;
- a hard-coded NYT API credential;
- local absolute `/Users/...` paths;
- the old Django personal website, including personal photos, documents, and SQLite data;
- copied DPhi NumPy bootcamp notebooks that were primarily third-party instructional material;
- MedNIST image files and compressed dataset archives;
- large SARS-CoV-2 raw/processed datasets and viral source metadata;
- NYT/stock and Steam scraped/retrieved CSVs;
- other large generated intermediates.

## Retained

- original notebooks that represent the user's own exploratory work;
- code needed to understand each project;
- selected user-generated aggregate plots/tables from the SARS-CoV-2 analysis;
- lightweight project documentation and setup notes.

This export intentionally favors a compact portfolio repository over a byte-for-byte archive of the original workspace.
